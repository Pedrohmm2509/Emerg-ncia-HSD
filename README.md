# Plantão Emergência HSD

PWA instalável para organização do plantão da Emergência.

## Publicação com GitHub Pages

1. Crie um repositório público no GitHub.
2. Envie todos os arquivos deste pacote para a raiz do repositório.
3. Abra Settings > Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Selecione a branch main e a pasta /(root).
6. Salve e aguarde a publicação.
7. Abra o endereço gerado no Safari do iPhone.
8. Toque em Compartilhar > Adicionar à Tela de Início.

## Observação de segurança

Esta versão salva dados apenas no navegador do dispositivo usando localStorage.
Não há autenticação nem sincronização em nuvem. Use apenas para testes com dados fictícios
até que o backend seguro seja implementado e aprovado institucionalmente.
